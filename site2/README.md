# Md. Ahasanul Adib | Portfolio

Personal research portfolio, hosted on GitHub Pages.

Live site: https://ahsanadib.github.io/Md.AhasanulAdib.github.io/

## How it works

It is a plain HTML, CSS and JavaScript site with no build step. All the content lives in one file:
`data/Profile/profile.json`. Edit that file to change the text, and the page updates.

- Project write-ups are Markdown files in `data/Projects/<project>/Description.md`.
- Photos and certificates sit in `data/` and `assets/proofs/`.
- The Download CV button points to `assets/files/Md_Ahasanul_Adib_CV.pdf`. Replace the PDF to update it.

## Run it on your computer

The page loads JSON, so open it through a local server, not by double-clicking:

```
python -m http.server 8000
```

Then visit http://localhost:8000

## Before you push anything

Everything in this folder becomes public. Do not add: joining or experience letters, the IELTS Test Report Form,
BPDB data files, phone numbers or any ID numbers.
